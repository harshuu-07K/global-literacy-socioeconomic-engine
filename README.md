# 🎓 Global Literacy & Socio-Economic Engine

An enterprise-grade analytics architecture that unifies distributed global data structures, processes complex illiteracy arrays, and serves multi-dimensional trends via an interactive, high-performance UI layer.

---

## 🛠️ Tech Stack & System Architecture

- **Data Processing Layer:** Python, Pandas, Logging Framework.
- **Storage Infrastructure:** SQLite3 relational engine optimizing transactional query speeds.
- **Frontend Layer:** Streamlit (Premium UI Injector Blueprint), Matplotlib, Seaborn.

---

## 🚀 Key Architectural Phases Completed

1. **Ingestion Framework:** Safely mapped and loaded extensive global metrics directly into temporary memory structures.
2. **Mathematical Processing:** Resolved indexing anomalies and handled missing value properties dynamically.
3. **Relational Push:** Compiled completely sanitized DataFrames into optimized SQLite database tables (`literacy_master`, `illiteracy_census`, `socio_economic_metrics`).
4. **UI Dashboard Engine:** Implemented direct relational database querying natively inside a dynamic web viewport.

---

## 📦 Project Directory Layout

- `core_pipeline/`: Advanced data cleansing & relational compiler.
- `data/`: Structured source environments and storage schemas.
- `app.py`: Premium analytics controller interface.
